# Generate Query Letter + Synopsis

Generate a professional query letter and synopsis for literary agent submissions.

## Steps

### 1. Gather manuscript information

- **Read `book_summary.md`** if it exists (generated by `/summarize`). This is the primary source for plot, characters, and resolution. If it doesn't exist, tell the user to run `/summarize` first.
- **Read the first 3 chapters** for voice, tone, and the opening hook
- **Read the last chapter** for the resolution and final emotional beat
- Get total word count from `novel.txt` file size (estimate ~5.5 characters per word) or run `/wordcount`

### 2. Ask the user for anything not provided in the arguments

- Genre classification (literary fiction, thriller, romance, etc.)
- Comparable titles (suggest 2-3 based on your read if the user doesn't have them)
- Author name
- Author bio highlights relevant to this book (publishing credits, expertise, or personal connection to the story)
- Any specific agents or publishers being targeted

### 3. Generate two documents

#### A. Query Letter (~400 words)

The query hooks without spoiling the ending.

```
Dear [Agent Name],

[HOOK: 1-2 sentences that capture the premise and stakes. Be specific.
"When X happens, Y must choose between Z and W" beats "In a world where..."]

[BODY: 150-250 words. Cover the protagonist, the central conflict, the stakes,
and what makes this story unique. Present tense, third person, even if the
novel is first person. End with a sense of what's at risk — but do NOT
reveal the resolution.]

[BOOK TITLE] is a [genre] novel, complete at [X,000] words. It will appeal
to fans of [Comp Title 1] by [Author] and [Comp Title 2] by [Author].

[BIO: 1-2 sentences. Publishing credits, relevant expertise, or why you
wrote this book. If no credits, focus on the personal connection.]

Thank you for your time and consideration.

Sincerely,
[Author Name]
```

#### B. Synopsis (1-3 pages, ~500-1500 words)

The synopsis MUST spoil the ending. Agents need to know the story works.

```
[TITLE] — Synopsis

[Full plot summary in present tense, third person. Cover:]

1. Opening situation — who is the protagonist, what's their world, what's the inciting incident
2. Rising action — the major complications, choices, and turning points
3. Midpoint shift — what changes the protagonist's understanding or stakes
4. Climax — the central confrontation or decision
5. Resolution — HOW IT ENDS. State this plainly. No teasing, no "and then everything changes..."

[For multi-POV novels: follow the primary narrative thread, weaving in
other POVs only where they change the main arc's trajectory.]

[For literary fiction: emphasize internal/thematic arc alongside plot.]
```

### 4. Save both files

- `query_letter.md` — the pitch letter
- `synopsis.md` — the full plot synopsis

### 5. Offer variations

Ask if the user wants:
- Versions tailored to specific agents (personalized opening lines referencing their wishlist or recent sales)
- A shorter pitch version (1-2 paragraphs for online submission forms or Twitter pitches)
- A longer synopsis (some agents request 3-5 pages)

## Guidelines

- The query letter hook must be specific to THIS book. No generic openings.
- Focus on protagonist's choice and stakes in the query, not a plot timeline
- Keep the query under 400 words
- The synopsis covers the FULL plot including the ending, plainly stated
- The synopsis should read as a compelling narrative, not a chapter-by-chapter list
- Comp titles should be: published within the last 5 years, same genre, recognizable but not mega-bestsellers
- Match tone to the book's tone. A funny book needs wit in the query. A dark thriller needs tension.
